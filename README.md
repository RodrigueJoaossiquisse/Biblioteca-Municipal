# 📚 Sistema de Gestão de Biblioteca Municipal

Sistema simples baseado em consola, desenvolvido em **Java**, para gerir o inventário de livros, utilizadores e empréstimos de uma biblioteca.

---

## Funcionalidades

- Registo de livros (ID, título, autor, ano, quantidade)
- Consulta de catálogo
- Pesquisa por título ou autor
- Empréstimo de livros (com atualização de quantidade)
- Devolução de livros
- Estatísticas (total de livros, empréstimos, livro mais emprestado)

---

## Pré-requisitos

- **Java JDK** (versão 17 ou superior) instalado
- **VS Code** (ou qualquer editor/terminal) para compilar e executar

---
